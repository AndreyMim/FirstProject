# Это первый проект в курсе Яндекс

## AQA

Учимся _автоматизировать_ и **тесты** текста.

### Заголовки разных уровней задают разным количеством символов решетки перед текстом:

# H1 — заголовок первого уровня, самый большой
## H2 — заголовок второго уровня, поменьше
### H3
#### H4
##### H5
###### H6 — заголовок шестого уровня, самый маленький 

### Разрыв строки создается двумя пробелами или кодом <br>

### Для начала нового параграфа нужно в конце строки поставить 2 символа переноса (нажать Enter два раза

### Выделение текста

#### ПКурсив — это *звёздочки* или _подчёркивания_

#### Полужирный шрифт — двойные **звёздочки** или двойные __подчёркивания__ 

### Списки

#### ПДля оформления нумерованного списка достаточно поставить в начало строки цифры с точкой.

#### ПНенумерованный список создаётся звёздочкой с пробелом в начале строки либо дефисом с пробелом.

### Для оформления текста в виде ссылки, его заключают в квадратные скобки, а затем указывают нужный адрес в круглых скобках, если после адреса добавить в кавычках название ссылки, то она будет отображаться как всплывающая подсказка.

### Для оформления кода, нужно окружить его тройками косых кавычек — грависов.

##HEAD -- это голова.
##Коммит -- это всему голова.
